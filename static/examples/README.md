# Built-in handwriting examples

These are MNIST test-set images, inverted to dark ink on white paper, enlarged to 220 × 220, and placed in a 640 × 480 photo canvas. The input pipeline processes them exactly like uploaded images. They were selected to be correctly classified by the bundled checkpoint; these ten demonstrations are not an accuracy evaluation.

Digit → zero-based MNIST test index: 0 → 3, 1 → 2, 2 → 1, 3 → 30, 4 → 4, 5 → 15, 6 → 11, 7 → 0, 8 → 61, 9 → 7.
